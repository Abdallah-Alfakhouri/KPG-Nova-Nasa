# Mission Architect

An interactive space mission design game by Team KPG Nova, ZU University, Jordan.
Built for the NASA Space Apps Challenge.

Play here: https://precious-praline-c364ae.netlify.app

## AI use
This project was developed with AI assistance: the initial app was generated with Figma Make, and later code, text, and visual design were created and refined with Claude (Anthropic). All artwork is drawn in code (CSS/SVG). No image files, photos, or NASA logos are used.
